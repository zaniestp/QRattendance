.NOTES
To use:
1. Please ensure that you have your Google worksheet ready on the second tab. The name does not matter.
2. The name of the of the data header of the Google Sheet must be the same as the field names in Form SG.
3. Please replace the Google Sheet ID with your ID in the script file.
4. Create a webhook, aka Custom API.
5. Use POST for format for the pipe
6. Create the same data schema in tiles in Pipes
7. Insert the correct JSON format data entry **key:data** format.
8. Remember to use Create New Row/Data in Pipes as the trigger.
9. Publish on Google and Pipes and you are ready to go!
